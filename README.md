# 22개정 선택과목 도우미 웹.
주요 기능은 다음과 같다.

과목 목록 및 분류: 다양한 선택 과목을 교과 영역과 과목 유형에 따라 살펴볼 수 있도록 한다.

과목 검색: 과목명을 검색하여 원하는 과목을 빠르게 찾을 수 있도록 한다.

과목 상세 안내: 과목별 학습 주제와 내용을 확인하여 해당 과목에서 무엇을 배우는지 이해할 수 있도록 한다.

진로별 과목 탐색: AI·데이터, 자연·공학, 생명·의학, 인문·사회 등 관심 분야와 관련된 과목을 탐색할 수 있도록 한다.

과목 간 연계 탐색: 관련 과목의 학습 관계와 기초·심화 과정을 파악하는 데 도움을 준다.

학업 계획 지원: 탐색한 과목을 고등학교 3년의 학업 계획과 연결할 수 있도록 한다.
